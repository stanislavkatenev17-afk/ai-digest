# Отбор новостей для выпуска

Турниры: АПЛ, Ла Лига, Лига 1, Бундеслига, Серия А, Лига чемпионов.

Выпуск — 3 отдельные статьи, по возможности из разных турниров. Только события за последние 7 дней.

Берём:
- Матчи: значимые результаты, дерби, матчи Лиги чемпионов.
- Трансферы: только официально подтверждённые клубом.
- Травмы звёзд: длительные травмы ключевых игроков.

Не берём:
- Слухи и «источники сообщают».
- Назначения и отставки тренеров.
- Рекламные анонсы, прогнозы, ставки.
- Новости без первоисточника.
