# Статьи дайджеста: формат и стиль

## Файл и frontmatter

Файл `src/content/blog/<basename>.md`, `<basename>` = `YYYY-MM-DD-slug` (дата выпуска + короткая часть латиницей).

```yaml
---
title: Заголовок до 60 символов без точки
description: Одно предложение до 160 символов.
pubDate: YYYY-MM-DD
heroImage: /covers/<basename>.webp
source: https://example.com/news
tags: [epl, match]
---
```

Для публикации обязательны `title`, `description`, `pubDate`, `heroImage`, `source`. Схема в `src/content.config.ts` пропускает пустой `heroImage`; обязательность проверяет Stop-хук `.claude/hooks/validate-article.js`.

Теги: турнир (`epl`, `laliga`, `bundesliga`, `ligue1`, `seriea`, `ucl`) + тип (`match`, `transfer`, `injury`).

## Формат

- Заголовок: до 60 символов, без точки.
- Описание: одно предложение до 160 символов.
- Тело: 300–500 слов, 2–4 абзаца.
- Источник: обязательная ссылка на первоисточник.

## Стиль

- Язык — русский.
- Тон формальный: деловой, третье лицо («команда победила», не «мы увидели»).
- Только факты из источника. Не додумываем голы, минуты, составы и места в таблице.
- Без маркетинговой лексики, канцелярита, разговорных оборотов и оценочных суждений.
- Предложения до 25 слов. Точки в конце пунктов списка.
- Без шаблона «от X до Y». Перечисляем конкретно.
- Без эмодзи.
